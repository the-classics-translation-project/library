# One bounded session

Read AGENTS.md. Generate or read `./ctp task` and inspect the repository.
Continue existing unfinished work, not just newly queued items. Read work notes
and target-language notes before generation. Preserve intermediate files and
record the source, model and prompts. Do not overwrite another active edit,
renumber source nodes, mark work human-reviewed, invoke paid APIs or publish
literary editions without authorization. Save, validate and state what remains.
For automated local preparation of one queued source, use
`prompts/source-preparation.md` and `docs/local-source-automation.md`,
not this general-purpose session prompt. Do not let source-preparation jobs
launch translation or declare the whole work published.
