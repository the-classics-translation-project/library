# Works

Real acquired works and their editable editions belong here. None has been imported
in version 0.1.0. Queue entries are intentions, not acquisitions.

Automatic US/Japan checks may create `gutenberg-<id>/rights.json` and retained RDF
evidence before a literary work is imported. Held requests contain reasons and no
automatically acquired source text. Passing requests also contain the permanent
`acquisition/` package, pending source-tree interpretation. See the
[automatic source-rights policy](../docs/automatic-source-rights.md).

Read [source import](../docs/source-import.md), [source structure](../docs/source-structure.md)
and [provenance](../docs/provenance.md). Each work has source metadata, an opaque-ID
tree, source/edition notes, target prose and compact generation records. The importer
creates the canonical tree from block references; do not invent semantic IDs.

Synthetic test text lives in examples/, not in the real library catalogue.
