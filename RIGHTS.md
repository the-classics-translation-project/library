# Rights and distribution

**Status: owner decisions and per-work clearance required.** No blanket license
for project code, documentation or new editorial text has been selected. This file
is not an open-source license or a declaration that an entire AI-generated edition
is copyrightable. Add LICENSE (and any scope-specific notices) after the owner
chooses terms. Repository visibility alone is not the project's licensing policy.

For Gutenberg source acquisition, the owner-authorized automatic US/Japan policy
in [docs/automatic-source-rights.md](docs/automatic-source-rights.md) permits the
workflow to commit a package only after both country checks and package checks
pass. It records the supporting evidence and decision. Uncertain cases stay on
hold without publicly committing their source text. This is a scoped project
admission rule, not human/legal review or a claim of worldwide public-domain status.

Versioned evidence may supplement missing provider publication data or record
exactly assessed ancillary Gutenberg credits; this does **not** authorize arbitrary
modern adaptations or waive source-level inspection. See per-work
`admission-evidence.json` and the v2 policy. The original package is preserved;
transcriber commentary must not be mistaken for the historical author's prose.

Record a source's edition evidence, provenance and rights basis before distributing
it. Consider the territories in which the edition will be offered, and distinguish
the historical work from later translations, apparatus, scans, images and other
material. A bare “public domain” flag is not a substitute for that record.

Each edition also needs a rights/distribution note for the new text and its human
contributions. Do not infer ownership or permission merely from the amount of AI
use, the number of edits, or a model's assertion. Never label AI revision as human
review. This version does not make a US/Japan copyright determination.

The public catalogue is an explicit distribution allowlist. A frozen review draft
can exist locally without being listed. **Putting files into a public repository
also distributes them**, even when GitHub Pages does not list them. Complete the
appropriate checks before committing real source material or drafts to a public
repository. A separate contributor route is not a privacy or authentication boundary.

The demonstration in examples/ is newly generated fictional test content. It has
no historical-author attribution and is not part of the intended public-domain
collection. Its local testing status is not a rights determination for future books.

Before KDP submission, check the current rights, metadata and AI-disclosure rules
in the account's applicable KDP documentation. There is no KDP submission or royalty
eligibility logic in this project. This document is an operational checkpoint,
not legal advice.
