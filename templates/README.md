# Metadata starting points

Copy/edit these through an agent after acquiring and inspecting the actual source.
They are not ready-to-publish works. `source-apply` creates structure.json and exact
body files from the AI’s block-reference plan; do not hand-name semantic node IDs.

Create target text files under editions/<edition>/text/. The edition node map points
to existing source IDs and translates their labels/prose. Omit missing fields in
drafts instead of creating placeholder prose. See docs/data-formats.md at the root.

`disposition.json` is an optional report-assessment record, not an automated patch.
Use notes to distinguish confirmed decisions from observations and open questions.
