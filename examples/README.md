# Synthetic test editions

`tree-work` is the current schema-v2 English/Japanese workbench example. It exercises
an opaque-ID source tree with branch prose and an unlabeled grouping, as well as
annotatable titles/headings, overlapping selections, emoji offsets and a deliberately
inconsistent name. It is not a literary publication or a quality-approved style model.

`demo-work` and its old snapshots remain as schema-v1 compatibility fixtures. Its
originally generated prose is not falsely attributed to the current migration model.

`./ctp build --demo --epub` opts into their preview pages. Normal builds never use
examples/catalog.json. Outgoing Issue links for fixture review pages are disabled.
The independent Admin request form is an actual project intake form and requires
a deployed repository and explicit GitHub submission to be useful.
